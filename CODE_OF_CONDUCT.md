# Code of Conduct

This project adopts the [Contributor Covenant, v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) as its Code of Conduct. The canonical text is at that URL.

## Project-specific notes

- **Scope.** The Code applies to all project spaces — GitHub issues, pull requests, commit messages, code review, the repository's discussions, and any holotype-related interactions in adjacent venues (mailing lists, Slack workspaces, conferences) where a participant is representing the project.

- **Reporting.** Concerns can be reported to brendenferland@gmail.com with subject line `[holotype CoC]`. Reports are treated confidentially. Acknowledgement within 7 days; resolution timing depends on severity and the parties involved.

- **Enforcement.** As a single-maintainer project, enforcement decisions are made by the project lead. For incidents involving the project lead, escalation paths include the user's institutional contact (currently the Adamson Lab at the University of Connecticut). The Covenant's standard enforcement guidelines apply: correction → warning → temporary ban → permanent ban, scaled to severity.

- **Good-faith disagreement vs. harassment.** Technical disagreement, blunt code review, and pushback on design decisions are not violations. Personal attacks, sustained derailment, harassment based on identity, and bad-faith engagement are. The line is whether the behavior makes the project's spaces hostile to participants.
